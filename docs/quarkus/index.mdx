Quarkus is a Java framework optimised for **fast startup, low memory, and native compilation via GraalVM**. Build for Kubernetes / serverless without giving up the ergonomic Java backend stack.

## Why Quarkus (for senior interviews)

- **Build-time work** — Quarkus moves dependency injection, ORM mapping, and config wiring to **compile time**. JVM-mode startup drops from seconds to milliseconds.
- **GraalVM native image** — produces a static binary with ~30 MB RAM footprint and ~50 ms startup. Crucial for serverless / scale-to-zero.
- **Reactive by default** — `Uni<T>` (one) and `Multi<T>` (many) via Mutiny. Sits beside imperative code cleanly.
- **Cloud-native posture** — Kubernetes manifests generated by extension, health/readiness probes wired by default, OpenTelemetry instrumentation built in.

In an interview, Quarkus typically comes up when the JD mentions **serverless**, **Kubernetes**, **native compilation**, or **Red Hat / OpenShift**.
