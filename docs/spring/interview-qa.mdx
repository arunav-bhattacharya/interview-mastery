# Interview Q&A & Checklist

## Interview Q&A
**Q: Why is constructor injection preferred over `@Autowired` on fields?**
A: Constructor injection makes dependencies explicit, the class testable without Spring, and the resulting instance immutable. Field injection hides dependencies and makes unit testing harder.

**Q: How does `@Transactional` work under the hood?**
A: Spring creates a proxy around the bean. Calls through the proxy open a transaction before invoking the method and commit / rollback after. **Self-calls don't go through the proxy** → no transaction.

**Q: What's the difference between `@RestController` and `@Controller`?**
A: `@RestController` adds `@ResponseBody` to every method → the return value is serialized directly. `@Controller` returns view names by default.

**Q: How do you debug a slow endpoint in Spring Boot?**
A: Enable SQL logging, add Actuator metrics, instrument with Micrometer / OpenTelemetry, profile with `jfr` / `async-profiler`. Often it's an N+1 query.

**Q: Sync HTTP vs. async messaging — when does each fit?**
A: Sync when the caller needs the result *now* (login, checkout). Async when the work is slow / bursty / decoupled (email, video encoding, analytics).
