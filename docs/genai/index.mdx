## How the path is shaped

Each week has the same shape: read or watch for ~2 hours, build for ~4 hours, write up what you learned for ~2 hours, with a buffer for debugging. You finish the week with a **deliverable repo** — by Week 8 you have eight of them, plus a capstone agent that hiring managers can poke at.

The curriculum deliberately resists framework-first thinking. You build a RAG pipeline before touching LangChain. You write a ReAct loop in 100 lines of Python before reaching for LangGraph. The frameworks are easier once you've felt the shape of the problem they solve.

## Anti-patterns to avoid

- **Tutorial dependency** — finishing courses without shipping anything.
- **Framework hopping** — rewriting your agent in three different frameworks before knowing which problem you're trying to solve.
- **Chasing every model release** — most weeks, the model isn't the bottleneck.
- **Over-engineering with backend rigor too early** — AI code is messier than your usual JVM stack; let it stay messy until evals tell you what's actually broken.
