A trie (a.k.a. prefix tree) stores a set of strings such that words with a
common prefix share the same path from the root. Lookup, insert, and "starts
with" run in `O(L)` where `L` is the word length — no hashing, no comparing
against every stored word.

## When you want one

- **Autocomplete / search-as-you-type** suggestions.
- **Word-search boards** (mass DFS over many target words at once).
- **IP routing** (longest prefix match).
- Replacing a `HashMap<String,…>` when you also need **prefix queries**.

## Reference: minimal trie in Java

```java title="Trie.java"
class Trie {
  static class Node {
    Node[] kids = new Node[26];
    boolean end;
  }
  private final Node root = new Node();

  public void insert(String w) {
    Node n = root;
    for (char c : w.toCharArray()) {
      int i = c - 'a';
      if (n.kids[i] == null) n.kids[i] = new Node();
      n = n.kids[i];
    }
    n.end = true;
  }

  public boolean search(String w)    { return find(w, true);  }
  public boolean startsWith(String p) { return find(p, false); }

  private boolean find(String s, boolean wholeWord) {
    Node n = root;
    for (char c : s.toCharArray()) {
      int i = c - 'a';
      if (n.kids[i] == null) return false;
      n = n.kids[i];
    }
    return !wholeWord || n.end;
  }
}
```

## Complexity

| Operation     | Time   | Space (per node)   |
| ------------- | ------ | ------------------ |
| Insert        | `O(L)` | one node per new char |
| Search        | `O(L)` | —                  |
| Starts-with   | `O(L)` | —                  |
