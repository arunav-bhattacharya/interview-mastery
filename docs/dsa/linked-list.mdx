# Linked Lists

A linked list is a sequence of nodes where each node holds a value and a pointer
to the next. There is no random access; you walk it. The interview value is not
the data structure itself — it is the **pointer manipulation** that linked lists
force you to be careful with.

## The four patterns

1. **Reverse** — flip `next` pointers as you walk; keep `prev` and `next` cached.
2. **Two-pointer (fast/slow)** — detect cycles, find the middle, find the k-th-from-end.
3. **Merge** — interleave two sorted lists with a dummy head node.
4. **Dummy node trick** — when the head itself might change, prepend a sentinel
   and return `dummy.next` at the end. Saves an entire branch of edge-case code.

## Reference: reverse in O(1) space

```java title="ReverseLinkedList.java"
class ListNode {
  int val;
  ListNode next;
  ListNode(int v) { val = v; }
}

public ListNode reverse(ListNode head) {
  ListNode prev = null;
  ListNode curr = head;
  while (curr != null) {
    ListNode next = curr.next;   // save
    curr.next = prev;            // flip
    prev = curr;                 // advance
    curr = next;
  }
  return prev;
}
```

## Complexity

| Operation         | Time     | Space  |
| ----------------- | -------- | ------ |
| Traverse          | `O(n)`   | `O(1)` |
| Reverse           | `O(n)`   | `O(1)` |
| Detect cycle      | `O(n)`   | `O(1)` |
| Merge two sorted  | `O(n+m)` | `O(1)` |

## Practice

- **Reverse linked list** — the canonical pointer drill.
- **Linked list cycle** — Floyd's tortoise & hare.
- **Merge two sorted lists** — sentinel + tail pointer.
- **Reorder list** — find middle, reverse second half, weave.
