# Heap / Priority Queue

A heap is a complete binary tree where every parent is ≤ (min-heap) or ≥
(max-heap) its children. The implementation lives in an array because of one
clean property: the children of index `i` are at `2i+1` and `2i+2`.

## When to reach for one

- **Top-K** anything: K largest, K closest to origin, K smallest costs.
- **Streaming median** (two heaps — a max-heap and a min-heap).
- **Merging K sorted lists / streams**.
- **Greedy schedulers**: earliest-deadline-first, A* path-finding.

## Reference: K-th largest in a stream

```java title="KthLargest.java"
class KthLargest {
  private final int k;
  private final PriorityQueue<Integer> min = new PriorityQueue<>();

  public KthLargest(int k, int[] nums) {
    this.k = k;
    for (int v : nums) add(v);
  }

  public int add(int v) {
    min.offer(v);
    if (min.size() > k) min.poll();
    return min.peek();
  }
}
```

Keep a min-heap of size `k`. The root is always the K-th largest seen so far —
constant-time peek, `O(log k)` per insert.

## Complexity

| Operation         | Time         |
| ----------------- | ------------ |
| Peek              | `O(1)`       |
| Push              | `O(log n)`   |
| Pop               | `O(log n)`   |
| Build from array  | `O(n)`       |

## Practice

- **K largest elements** — bounded min-heap.
- **Merge K sorted lists** — push the front of each list; pop, advance, push.
- **Find median from data stream** — two heaps in balance.
- **Reorganize string** — max-heap of remaining character counts.
