## Array Manipulation Tricks

A few specialised array techniques that don't warrant their own spoke but come up in interviews:

### Rotate Array (in place)

> Rotate `nums` by `k` steps to the right. `O(n)` time, `O(1)` space.

**Trick:** reverse the whole array, reverse the first `k` elements, reverse the remaining `n - k`.

```java
void rotate(int[] nums, int k) {
    int n = nums.length;
    k %= n;
    reverse(nums, 0, n - 1);
    reverse(nums, 0, k - 1);
    reverse(nums, k, n - 1);
}
private void reverse(int[] a, int lo, int hi) {
    while (lo < hi) {
        int t = a[lo]; a[lo++] = a[hi]; a[hi--] = t;
    }
}
```

Why three reversals? Each shifts elements past one boundary; together they realise a rotation without any auxiliary array.

### Product of Array Except Self

> For each index `i`, return the product of every element **except** `nums[i]`, with no division and in `O(n)` time.

**Trick:** compute prefix products left-to-right, then multiply by suffix products right-to-left in a second pass.

```java
int[] productExceptSelf(int[] nums) {
    int n = nums.length;
    int[] out = new int[n];
    out[0] = 1;
    for (int i = 1; i < n; i++) out[i] = out[i - 1] * nums[i - 1];   // prefix
    int suffix = 1;
    for (int i = n - 1; i >= 0; i--) {
        out[i] *= suffix;
        suffix *= nums[i];
    }
    return out;
}
```

`O(1)` extra space if you don't count the output array.

### Other smaller patterns

- **Cyclic sort** — when the array contains values in `[1, n]`, sort in place by swapping each value to its correct index. Find-missing-number variants.
- **Boyer–Moore majority vote** — find the strict majority element in `O(n)` time, `O(1)` space.
- **Encoding by sorted key / counts** — group anagrams, find duplicates, detect rotations.
