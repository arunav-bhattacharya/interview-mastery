# Two Pointers

### What is Two Pointers?

Two Pointers is a technique that uses **two index variables** to traverse an array or string, advancing them strategically based on the data. Instead of nested `O(n²)` loops, two pointers often achieve `O(n)` time.

The key insight: by moving pointers intelligently, you can eliminate large portions of the search space in each step — similar in spirit to binary search, but applied to different problem shapes.

### Why Does It Work?

- **Sorted data has structure.** If `a[l] + a[r]` is too small, growing `l` is the only way to grow the sum. If it's too big, shrinking `r` is the only way to shrink it.
- **Each move eliminates possibilities** that brute force would have re-checked.
- **Invariants are maintained** — "everything before `l` is processed", "everything after `r` is done" — and these invariants prove correctness.

### Mental Model

Two pointers form a pincer:

- **Opposite-end pointers** are two people searching a sorted bookshelf from both ends, meeting in the middle.
- **Same-direction (fast / slow) pointers** are runners on a track at different speeds — perfect for detecting cycles or maintaining a window.

### When to Use

- Sorted arrays.
- Finding pairs / triplets that satisfy a condition.
- Removing duplicates in place.
- Palindrome problems.
- Comparing elements from both ends.

### Core Concept

```text
Two Pointers Pattern
┌─────────────────────────────────────────────────────────┐
│  Array: [1, 2, 3, 4, 5, 6, 7, 8, 9]                     │
│           ↑                       ↑                      │
│          left                   right                    │
│                                                          │
│  Move pointers based on a condition:                    │
│    • If sum < target  →  l++                            │
│    • If sum > target  →  r--                            │
│    • If sum == target →  done                           │
└─────────────────────────────────────────────────────────┘
```

  title="PairSum"
  java={`public int[] pairSum(int[] a, int target) {
  int l = 0, r = a.length - 1;
  while (l < r) {
    int s = a[l] + a[r];
    if (s == target) return new int[] { l, r };
    if (s < target) l++;
    else            r--;
  }
  return new int[] { -1, -1 };
}`}

### Common Mistakes to Avoid

- Forgetting to handle empty arrays.
- Off-by-one with `l < r` vs. `l <= r` — opposite-end search uses **strict** `<`.
- Not skipping duplicates in 3-Sum → duplicate triplets in the output.
- Modifying the array while iterating with stale pointer logic.
