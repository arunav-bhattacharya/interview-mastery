# HashMap / Frequency Count

### What is HashMap / Frequency Count?

A hash map gives **O(1) average lookup, insert, and delete by key**. The "frequency count" pattern uses one to count occurrences (characters, numbers, prefix sums) and answer questions in a single pass.

### Why Does It Work?

Many array / string problems reduce to "have I seen this before?" or "how many times?". A hash map answers both in constant time, eliminating an entire `O(n)` inner loop.

### Mental Model

Walk the array once. As you go, ask:

- **Have I seen this value before?** → store it as you visit.
- **Have I seen a complementary value?** → look it up to decide.

### When to Use

- Lookups against earlier values (Two Sum, prefix sums).
- Counting / grouping (anagrams, top-K frequent).
- Detecting duplicates or first-non-repeat.
- O(1) presence check inside another loop.

### Core Concept

```text
For each element x:
  if (target - x) in seen:  → found a pair
  else:                      → seen[x] = index
```

  Map<Integer, Integer> seen = new HashMap<>();
  for (int i = 0; i < nums.length; i++) {

### Common Mistakes to Avoid

- Storing the value instead of the index when the problem wants indices.
- Inserting before lookup → an element matches against itself in Two Sum.
- Using a `List` for frequency counts when a `Map` is cheaper.
- Forgetting that hash collisions degrade hot loops; a bad `hashCode` can turn `O(1)` into `O(n)`.
