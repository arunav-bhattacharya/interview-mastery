# Heap (preview)

A short preview — the dedicated hub is at [Heap & Trie](../heap-trie/index.mdx).

A **heap** keeps the smallest (or largest) element accessible in `O(1)` and supports `O(log n)` insert / extract. Use a heap whenever you ask "what's the next smallest / largest?" repeatedly — top-K problems, merging K sorted streams, finding the streaming median, Dijkstra's algorithm.

```text
Min-heap invariant: parent ≤ children
Stored compactly in an array — parent(i) = (i − 1) / 2
```

A **bounded heap of size K** answers "top K largest" in `O(n log K)` time and `O(K)` space — much better than sorting the whole input.
