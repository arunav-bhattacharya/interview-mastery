Almost every tree and graph problem reduces to a traversal — either
breadth-first (level by level) or depth-first (down one branch first).
Knowing **which to reach for** is half the win.

## When to pick which

| Picking BFS                                  | Picking DFS                            |
| -------------------------------------------- | -------------------------------------- |
| Shortest path on an unweighted graph         | Topological order / cycle detection    |
| Level-order traversal (per-level work)       | Tree path sums, ancestors              |
| Minimum number of edges / moves              | Backtracking (permutations, subsets)   |
| Multi-source spread (rotting oranges)        | Connected components on small graphs   |

## Reference: BFS on a graph

```java title="GraphBFS.java"
public List<Integer> bfs(List<List<Integer>> g, int start) {
  List<Integer> order = new ArrayList<>();
  boolean[] seen = new boolean[g.size()];
  Deque<Integer> q = new ArrayDeque<>();
  q.offer(start); seen[start] = true;
  while (!q.isEmpty()) {
    int u = q.poll();
    order.add(u);
    for (int v : g.get(u)) {
      if (!seen[v]) { seen[v] = true; q.offer(v); }
    }
  }
  return order;
}
```

## Reference: DFS on a tree (post-order)

```java title="PostOrder.java"
public void postOrder(TreeNode root, List<Integer> out) {
  if (root == null) return;
  postOrder(root.left,  out);
  postOrder(root.right, out);
  out.add(root.val);
}
```

## Complexity

| Algorithm | Time       | Space      |
| --------- | ---------- | ---------- |
| BFS       | `O(V + E)` | `O(V)`     |
| DFS (rec) | `O(V + E)` | `O(h)`     |
| DFS (it.) | `O(V + E)` | `O(V)`     |

## Practice

- **Binary tree level-order** — BFS, group by level.
- **Number of islands** — DFS / BFS over a grid.
- **Course schedule (II)** — topological sort, DFS or Kahn's.
- **Shortest path in a binary matrix** — BFS with directions.
