## Why Kotlin (for senior interviews)

- **Null safety at the type level** — kills entire bug classes the JVM compiler never caught.
- **Data classes + sealed interfaces** — algebraic data modelling without ceremony; perfect for DTOs, results, and state.
- **Coroutines** — the most pleasant concurrency model on the JVM, especially with structured-concurrency `coroutineScope`.
- **First-class interop with Java** — you can adopt Kotlin module-by-module in a Spring codebase.

If you're interviewing for a backend role that mentions "Kotlin/JVM", expect questions on **coroutines vs. virtual threads**, **null safety vs. Optional**, and **data classes vs. records**.
