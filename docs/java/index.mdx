## Suggested study order

1. **Java Core** — make sure the JVM, GC, collections, streams baseline is solid.
2. **Concurrency** — the area most senior candidates lose points on. Spend the most time here.
3. **Modern Java** — learn the new language tools and what older patterns they replace.
4. **Interview Q&A** — the last-mile drill before interviews.

(Pair this with the **Design Patterns** section under Skills for OOD interview prep.)

## Senior expectations — what an interviewer is listening for

- **Trade-offs over recipes** — when asked "how would you do X", explain the *choice* between A and B, not just A.
- **Production reality** — debugging stories beat textbook answers (memory leaks you traced, threading bugs you fixed, GC tuning you applied).
- **Modern over legacy** — reach for records / sealed types / virtual threads where appropriate, not just because they're new.
- **Failure thinking** — what happens when the disk is full, the heap is exhausted, two threads race, the connection drops?
- **Communication** — speak the names: *happens-before*, *escape analysis*, *N+1*, *idempotent*, *contention*. Vocabulary signals depth.
